# HH-bot

Кроссплатформенный (Windows/Linux) ИИ-агент для помощи в поиске работы на [hh.ru](https://hh.ru).

## Возможности

1. Просмотр и управление профилем пользователя
2. Встроенный ИИ-агент
3. Анализ hh.ru по вакансиям: поиск, составление списка, подготовка резюме
4. Создание откликов и сопроводительных писем
5. Режимы работы:
   - **Подтверждение** — пользователь подтверждает действия агента
   - **Полное доверие** — агент всё делает сам (письма, отклики) без участия пользователя
6. Агент работает, пока включена программа
7. Постоянные системные уведомления с возможностью настройки внутри программы
8. Полноценный графический интерфейс

## ИИ-агент для поиска

Используется OpenAI-совместимый API (приоритет — Responses API). Пользователь сам добавляет URL и ключ; программа находит модели у провайдера, либо провайдер указывается явно. Настраиваются лимиты (запросов в минуту и т.д.).

У агента есть инструменты (поиск в сети, просмотр страниц и т.д.) — он полноценно ищет вакансии, создаёт резюме и ведёт диалоги с работодателями.

## Как это работает

При первом запуске пользователь:

1. Подключает ИИ (URL и ключ)
2. Вводит информацию о себе (для контекста ИИ)
3. Подключает профиль hh.ru
4. Настраивает программу

Далее пользователь задаёт (и может менять) теги вакансий, желаемый формат работы (на месте, удалённо, гибрид), пожелания по зарплате и т.д.

После настройки агент проходит по hh.ru, отбирает вакансии, готовит резюме под навыки (для максимального совпадения) и формирует полноценное резюме для hh.ru. Если пользователь одобрил базовое резюме — агент загружает его и начинает рассылать отклики с сопроводительными письмами: автоматически или по подтверждениям, в зависимости от настроек.

## Сборка и запуск на Linux

Требования: Rust (https://rustup.rs), Node не обязателен (фронтенд статический).

1. Системные зависимости (Debian/Ubuntu):
   ```
   sudo apt install build-essential libwebkit2gtk-4.1-dev libxdo-dev \
     libayatana-appindicator3-dev librsvg2-dev patchelf
   ```
2. Сборка и запуск в режиме разработки:
   ```
   cd HH-bot/src-tauri
   cargo run
   ```
3. Сборка пакета (.deb):
   ```
   cargo tauri build   # или: cargo build --release
   ```

### Первый запуск

1. Запустите приложение — откроется экран входа. Нажмите «Войти через hh.ru»,
   войдите на сайте, затем вставьте в приложение код подтверждения (или всю
   ссылку, которую покажет hh.ru). Регистрация приложения на dev.hh.ru не нужна.
2. После входа открывается вкладка «Профиль» — данные аккаунта и список резюме.
3. Вкладка «Настройки» — ИИ-провайдеры: можно добавить несколько
   OpenAI-совместимых API (название, base URL, ключ, модель), проверить
   подключение и выбрать активный.
